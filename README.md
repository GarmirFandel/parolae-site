# parolae-site

Sito di Parolæ su https://parolae.com, pubblicato con GitHub Pages dal branch `main`.

- `index.html` – pagina di presentazione
- `privacy/index.html` – privacy policy (la fonte è `docs/PRIVACY.md` nel repo dell'app: cambiale insieme)
- `app-ads.txt` – editore AdMob autorizzato (richiesto da AdMob alla radice del dominio)
- `CNAME` – dominio personalizzato per GitHub Pages
- `assets/` – logo, icona e font (Playfair Display e Manrope, licenza OFL), inclusi qui per non contattare Google Fonts
